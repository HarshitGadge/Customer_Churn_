# Data

`customer_churn_large_dataset.xlsx`: 100,000 subscribers × 9 columns
(CustomerID, Name, Age, Gender, Location, Subscription_Length_Months, Monthly_Bill, Total_Usage_GB, Churn).

The file isn't committed here. A public copy is available in
[bholanathmishra/customer-churn-prediction-ml](https://github.com/bholanathmishra/customer-churn-prediction-ml).
Place it at `data/customer_churn_large_dataset.xlsx`.
